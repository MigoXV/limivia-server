# 工作台交互契约

主范式：实时工作台。辅助范式：引脚参数配置。默认白垣主题；MANAS 决定页面关系，苍渊·白垣决定视觉 Token。

| 状态 | 来源 | 呈现和可用动作 | 恢复 |
|---|---|---|---|
| 未连接 | 初始、主动断开 | 空读数；可选择 USB/BLE、连接；不能输出 | 连接并握手 |
| 连接中 | 用户选择设备 | 明确连接中，禁止重复连接 | 取消或失败后恢复连接按钮 |
| 就绪 | hello 成功 | 显示身份、引脚及能力，允许配置 | 每 1.5 秒刷新 |
| 执行中 | 一条用户命令待应答 | 禁止重复提交与断开，保持当前值 | 完成后同步设备状态 |
| 状态失效 | 请求超时、连接丢失 | 保留旧值并标记失效，禁用普通输出 | 刷新或重连；停止全部输出仍可尝试 |
| 操作失败 | 设备拒绝或传输错误 | 错误靠近工作区，提供刷新状态 | 新操作清除旧错误，刷新后恢复控件 |
| 能力不可用 | API 缺失或非安全上下文 | 显示浏览器/安全上下文指导 | 使用支持的浏览器/localhost/HTTPS |

控件：连接方式为有限选择；引脚与方向为有限选择；频率、时间为紧凑带单位数字输入；占空比为可键盘操作的滑块；启动/应用为当前任务主操作；停止与释放靠近作用域；总停止持续可发现。

桌面侧栏提供功能导航，主任务区与设备上下文并列；中宽将上下文下移；窄屏导航横向滚动，连接与当前功能优先，板卡图隐藏，状态与停止操作保留。数据数值使用等宽数字；日志最多 200 条，采样最多 120 条，避免无限增长。

无需依赖颜色判断：状态、占用、错误均有文字。键盘支持 skip link、原生表单语义和可见焦点；减少动效偏好下关闭过渡。图为功能示意，不作为接线图。
