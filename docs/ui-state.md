# 工作台交互契约

主范式：实时工作台。辅助范式：引脚参数配置。默认白垣主题；MANAS 决定页面关系，苍渊·白垣决定视觉 Token。

界面来源：[Figma 当前 UI 快照](https://www.figma.com/design/9WbAWG0bfGyDgJPDugJMTh/?node-id=33-2887)。同步覆盖 LED、GPIO、PWM、ADC、本地定时及连接、资源、日志和帮助。设计中的示例设备名与读数不进入生产状态；设备确认、固件能力和真实板型约束优先。

板载 LED 页与公共导航后续同步自 [1440×900 白垣设计](https://www.figma.com/design/AzGxH7vvqqpSfxBXUBRYbf/limivia?node-id=33-2888)。桌面控制区与 384×168px 状态区并列，底部说明使用相同列对齐；两种 LED 模式共享固定尺寸动作入口。切换输出或等待确认时保持几何位置，设备确认反馈分别说明点亮或熄灭，未知状态不显示为已熄灭。导航中的“板载定时”仍指芯片端执行的本地任务。

| 状态 | 来源 | 呈现和可用动作 | 恢复 |
|---|---|---|---|
| 未连接 | 初始、主动断开 | 首次无读数，断开后保留最后已知读数并标记失效；默认 BLE，可选择 USB/BLE、搜索后端设备并连接；不能输出 | 连接并握手 |
| 搜索中 | 用户点击搜索设备 | 禁止重复扫描与切换通道，显示搜索中 | 成功后选择候选；空列表与失败分别提示 |
| 连接中 | 用户选择后端设备并连接 | 明确连接中，禁止重复连接与搜索 | 失败后恢复连接按钮 |
| 就绪 | hello 成功 | 显示身份、引脚及能力，允许配置 | 每 1.5 秒刷新 |
| 执行中 | 一条用户命令待应答 | 禁止重复提交与断开，保持当前值 | 完成后同步设备状态 |
| 状态失效 | 请求超时、连接丢失、硬件执行结果未知或状态读取失败 | 保留旧值并标记失效；暂停轮询和输出操作，禁止重复提交 | 手动读取或重连并同步成功后恢复；读取失败仍保持失效 |
| 操作被拒绝 | 固件明确返回参数、保护或资源占用错误 | 错误靠近操作，保留已确认状态；失败的状态查询不会使旧快照恢复有效 | 修正参数或占用后重试 |
| 后端设备不可用 | 系统蓝牙、串口权限、设备占用或后端连接失败 | 显示后端适配器/权限/连接指导 | 修复后端环境后重新搜索；占用时先断开原页面 |

控件：右上角打开连接页，默认蓝牙；搜索按钮发现后端设备，设备选择器展示真实候选，一个候选时预选、多个候选时需手选；切换连接方式清除旧候选、错误与提示。引脚与方向为有限选择，频率、时间、占空比均为带单位的数字输入。未连接时允许编辑草稿，启动/应用才提交设备；等待确认期间禁止重复操作。GPIO 的模式与电平随配置一起提交，读数保留设备已确认值；草稿模式与设备模式不一致时，标题为“设备当前读数”并提示“工作模式尚未应用”，收到确认后才显示对应的输入或输出标题。PWM 表格区分编辑值和设备已确认值，模式切换本身不静默覆盖另一实验的占用。

桌面采用 48px 顶栏、176px 侧栏和主任务区，帮助在页面标题右侧；中宽内容下移成单列；窄屏导航横向滚动。板卡资源通过“板卡与引脚”打开，包含当前引脚占用、释放、总停止与实物接线图入口。底部打开“命令与事件”。弹窗支持 Escape 关闭并将焦点还给触发按钮，嵌套接线图逐层关闭；执行确认期间不能关闭确认框。

释放引脚、停止定时任务、停止全部输出和主动断开需确认；取消不会写设备。LED 停止呼吸或切回开关时先确认停止并读取，不自动点亮。PWM 页停止当前 PWM、ADC 页停止采样为直接操作，即使参数草稿无效也可停止；ADC 停止后保留采样，导出仅包含当前引脚。断开前说明任务仍可继续，重连只读取状态，不重放创建或输出命令。

数据数值使用等宽数字。日志最多 200 条，当前连接采样最多 120 条，按目标引脚筛选后曲线显示最近 60 条；重连清空旧采样。无采样不等于 0V；电压和原始值来自设备，曲线仅在所展示样本均有校准电压时使用电压，否则使用原始值。失联读数标记过期，曲线不代表端到端延迟。ADC 纵轴文字保持固定字号，不随窄屏曲线缩放。

无需依赖颜色判断：状态、占用、错误均有文字。键盘支持 skip link、原生表单语义和可见焦点；减少动效偏好下关闭过渡。资源弹窗板图仅为功能示意，未沿用设计中的简化排针标签；实物接线另用已有的 32 引脚映射，核对丝印和板型后使用。

设备归后端电脑管理，浏览器不读取本机蓝牙/串口能力。连接会话独占后端设备通道，页面关闭与网络断开后释放连接；下次连接重新握手，旧读数保持失效直至同步成功。
