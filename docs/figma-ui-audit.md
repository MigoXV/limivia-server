## 业务与交互检查

- 导航支持来自本次 `discovery.operations/resources`，文件使用实际的 `storage.*` 能力。设计示例中禁用的入口不会被照抄成某个 profile 的固定限制。
- 配置草稿和侧栏选中均属于前端视图，不创建资源。点击当前主导航保留正在编辑的草稿；切换到另一资源仅改变当前选择，不重新创建资源。
- 资源列表来自当前连接代次的快照。更换连接或固件身份后旧选择失效；占用来源不等于当前页面取得了控制。
- 未创建资源、过期状态、未知结果和其他来源占用保持明确文字；不显示成已熄灭。LED 的开关、呼吸、读取、模式切换确认及权限仍使用原有业务链路。
- 侧栏中部独立滚动，顶部上下文与底部辅助入口保留；正文和首页能力表支持键盘滚动。650px 以下改为顶部导航网格；窄屏和 200% 放大检查无水平溢出。
- “引脚与占用”按新版放在外设等设备页面的辅助区，首页和流程页面可从“固件与能力”弹窗访问。主题切换保留在底部版本行；这是为保留原有操作补充的小型文本入口。
- 设计的固件、资源、波形与流程为示例。既有业务表单继续按设备能力生成，不将示例数据当作设备输出或物理测量。LED 标注保留“输出示意 · 非物理测量”。

## V5：板卡、物理引脚与共享接线组

本轮按用户确认的产品方向合并首页和外设调试：中央完整实物板图作为起点，主侧栏展示接线组和未归组的设备配置，右侧按当前选择展示配置与调试。软件功能目录降为选针后的能力选择器；选择单引脚功能自动带入起始 GPIO，多角色功能先明确该引脚角色，再从板图或选择框补齐整组。I²C / SPI 子设备从所属总线进入，片内温度等保留无引脚入口。

接线组名称、参数、供电位置和备注是人工记录的意图，保存服务器方案不产生硬件写入。方案按设备隔离，用 revision 事务比较保护共享编辑；收到远端更新时，未编辑页面更新显示，编辑中的页面保留本地修改并提示冲突。检查与应用分别确认；应用捕获保存版本，重新预检并逐组创建，不替换已有运行资源，不自动回滚或重试未知写入。原始动作、作业和资源实例继续来自 SDK。HTTP 元数据接口独立记录在 [接线方案说明](wiring-plan.md)，固件协议未改变。

### D5 首次入口与定位提示

GPIO13 绿色焊盘内部加入 16×14 的 LED 线性矢量，其他引脚不显示该符号。Figma 与代码使用相同路径；透明度按 1→0.65→1 轻微呼吸，每周期 2.4 秒，共三次后停止。它只提示 D5 位置，不宣称物理灯已点亮；应用在 `prefers-reduced-motion: reduce` 下完全关闭动画。

两个桌面和两个小窗口首页默认展开 LED，但仍处于 Observe；点亮按钮禁用，并提示先取得设备控制。取得控制进入对应 NoResource 状态，点亮后才进入确认流程；释放控制返回观察首页。LED 组件共 28 个状态，覆盖首次未知、最近确认值、开关与呼吸切换、读取、关闭和释放；主按钮宽 104px、反馈区高 40px，延续此前防抖动与防闪烁语义。原型定时跳转只表达交互，不代表真实设备确认。
